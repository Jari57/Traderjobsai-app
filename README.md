# Trade Jobs AI 🔧⚡❄️

> AI-powered home services platform — Plumbers, Electricians & HVAC

Trade Jobs AI is a multi-agent marketplace that estimates, negotiates, and manages the entire home repair lifecycle — from intake to verified completion.

## 🌊 Full Workflow

```
Intake → AI Analysis → Summary (Agent 1) → Estimator (Agent 3) → Quote Deck → Negotiator (Agent 4) → Foreman (Agent 6)
```

## ✨ Features

### Intake
- **Immersive Blue Hero Header** — search bar with voice & camera input
- **IoT Smart Trigger** — simulates Flume water sensor detecting a pipe leak at 2 AM
- **AR LiDAR Scan** — spatial mapping for exact part fitment

### Agent 1 · Intake Coordinator
- 4-step vertical timeline: Transcript → Analysis → Qualification → Strategy
- Agent statistics: agents deployed, data points, analysis time, confidence score

### Agent 3 · The Estimator
- Line-item price breakdown (labor, materials, permits, overhead)
- **Live inventory** — simulates real-time Home Depot stock check
- **BNPL** — Affirm financing options (3, 6, 12 months)

### Quote Deck
- Sortable contractor cards (rating, price, fastest ETA)
- Reliability scores, badges, and review counts

### Agent 4 · The Negotiator
- **Structured bidding** — no chat, just offer/counter mechanics
- **3-counter limit** — creates urgency and realistic haggling
- Contractor auto-counters back toward a target price

### Agent 6 · The Foreman
- **Milestone tracker** — live status per job phase
- **AI Vision Before/After Slider** — drag to compare photos
- **Scope Creep Manager** — real-time change order approval (+$185)
- **Yale Smart Lock** — one-time PIN provisioning via geofence
- **Live Map Tracker** — Uber-style dispatch tracking

### Broker Dashboard
- GMV, active job count, satisfaction score
- **Instant Payout Factoring** — 1.5% fee for same-day payout
- Job queue table with status badges
